# 꾸끼런 — 유키나 도트 러너

미나토 유키나가 쿠키를 모으며 무대로 향하는 BanG Dream! 비공식 도트 팬 게임입니다. 고군분투의 자동 달리기·점프 동작에서 영감을 받았습니다.

## 포함된 이미지와 외부 자료

캐릭터 이미지는 이 프로젝트에서 이미지 생성 도구로 제작했습니다. 원본과 생성 프롬프트(`source-art/`), 실행에 필요한 내장 이미지 스크립트(`docs/assets/`)를 함께 포함합니다. 외부에서 다운로드한 원작 이미지·음원은 포함하지 않으며, `reference-art/`와 `external-assets/`는 Git에서 제외합니다. 미셸 공·쿠키 상자·동행 고양이는 직접 작성한 Canvas 코드로 그립니다.

## 바로 실행

`docs/index.html`을 브라우저로 열면 됩니다. 설치·빌드·서버·API 키가 필요 없습니다. 폰트만 Google Fonts에서 불러오며, 연결이 없어도 기본 폰트로 게임이 실행됩니다.

## GitHub Pages 배포 — 웹에서 올리기

1. GitHub에서 빈 저장소를 만들고 압축을 푼 폴더 안의 `docs` 폴더와 `README.md`를 `main` 브랜치에 올립니다. 저장소 최상위에 `docs/index.html`이 있어야 합니다. ZIP 파일 자체를 올리면 실행되지 않습니다.
2. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. 브랜치는 **main**, 폴더는 **/docs**로 설정하고 **Save**를 누릅니다.
4. 배포가 완료되면 같은 Pages 설정 화면에 표시되는 URL로 플레이합니다. 이후 `docs` 안의 게임 파일을 수정하면 다시 배포됩니다.

이 방법은 숨김 폴더인 `.github`를 업로드하지 않아도 됩니다. 계정 요금제에 따라 비공개 저장소의 Pages 지원이 다르므로 GitHub Free라면 공개 저장소를 사용하세요.

## GitHub Actions 자동 배포

Git으로 올리는 경우 포함된 `.github/workflows/pages.yml`을 사용할 수 있습니다.

1. 이 폴더의 **내용 전체**를 저장소 루트에 커밋합니다. `.github/workflows/pages.yml`과 `docs/index.html`의 위치를 유지하세요.
2. 저장소의 **Settings → Pages → Source → GitHub Actions**를 선택합니다.
3. `main` 브랜치에 push하거나 **Actions → Deploy Kkukki Run to GitHub Pages → Run workflow**를 실행합니다.
4. 실행이 완료되면 해당 작업의 `github-pages` 링크에서 플레이합니다.

브랜치 배포와 Actions 배포 중 하나만 선택하면 됩니다. 기본 브랜치가 `main`이 아니라면 워크플로의 `branches` 값을 실제 브랜치 이름으로 수정하세요. 게임 파일은 상대 경로를 사용하므로 일반 저장소의 `/저장소명/` 주소에서도 동작합니다. 별도 토큰이나 저장소 Secret은 필요 없습니다.

배포 참고: [GitHub Pages 공식 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## 조작

| 입력 | 동작 |
| --- | --- |
| 스페이스 / 화면 클릭 / 모바일 버튼 탭 | 점프 |
| 손을 뗀 뒤 공중에서 다시 누르기 | 이단점프 |
| P | 일시 정지 / 재개 |
| R | 처음부터 다시 시작 |
| M / 음표 버튼 | 소리 켜기 / 끄기 |

길게 누르기나 키 반복은 추가 점프를 만들지 않습니다. 착지하면 점프가 두 번으로 초기화됩니다. 머리 위 점 두 개가 남은 횟수입니다. 발판을 그냥 걸어 나왔다면 공중 점프 한 번으로 복귀할 수 있습니다.

소리는 기본으로 켜져 있으며, 게임 시작 입력 후 재생됩니다. M 키나 음표 버튼으로 끌 수 있습니다. Web Audio로 합성한 오리지널 신스 패턴이며 공식 음원은 포함하지 않았습니다.

## 게임 내용

- **한 번에 이어지는 10분 코스.** 세 번의 기회를 모두 쓰면 처음부터 다시 시작합니다.
- 시작 속도는 480px/s입니다. 쿠키 보너스 없이 30초에 약 705, 1분에 약 814, 2분에 약 896px/s까지 올라갑니다. 이후에도 계속 증가하며 최종 기본 속도는 1,000px/s, 쿠키 보너스를 합치면 최대 1,040px/s입니다.
- 기본 점수는 일반 쿠키 +10점, 고양이 쿠키 +30점이며 스트릭 배율이 적용됩니다. 16,000점에서 최대 40px/s의 추가 가속을 얻습니다. 최고 점수는 이 브라우저에 저장합니다.
- **이단점프:** 첫 점프가 정점에 가까워질 때 다시 누르면 더 멀리 갑니다. 넓은 틈은 일반 점프의 최대 거리보다 길고 이단점프로는 통과하도록 조정했습니다. 2차 점프에는 발밑 효과가 나옵니다. 화면 상단에서는 상승이 제한됩니다.
- **미셸 공:** 분홍색 귀·별 모양 눈·크림색 주둥이를 그린 미셸 공이 회전하며 왼쪽으로 굴러옵니다. 더 많은 지형 조합에 등장하며 한 번에 2~4개씩 이어집니다. 접근 효과음을 내며, 약 1.25~1.5초 간격으로 마주치도록 배치해 점프 후 짧게 착지하고 다시 뛰게 합니다. 발판 끝을 넘으면 아래로 떨어집니다.
- **3단 연속 계단:** 착지 후 곧바로 다시 점프해 세 발판을 차례로 올라갑니다. 단계마다 36~44px 높아지며, 달리기 속도에 맞춰 간격과 폭을 조정합니다. 정상에는 쿠키가 모인 넓은 착지대가 있습니다.
- 로프 홀드·스윙·엇갈리는 차단기는 제거했습니다.
- 짧은 점프·긴 점프·상승·하강·이단점프·장비 장애물·갈림길·이동 발판·굴러오는 장비·연속 계단·쿠키 정원을 연속으로 조합합니다. 한 판에서 지나간 동작 순서 전체를 기억해 같은 조합을 다시 사용하지 않습니다.
- 청록색 발판은 위아래로 움직이고, 캐릭터와 쿠키도 따라 움직입니다. 위쪽 쿠키 길과 아래쪽 기본 경로를 선택할 수 있습니다.
- 기본 쿠키 간격은 75px, 보너스 경로는 55px입니다. 미셸 공의 시작 위치에는 쿠키를 겹쳐 두지 않습니다.
- 소리·전체화면 버튼에 포커스가 있어도 스페이스로 점프합니다. 키보드와 터치가 동시에 눌려도 점프가 두 번 소비되지 않습니다. 착지 직전 입력 버퍼와 발판 끝의 짧은 점프 유예 시간을 유지합니다.
- 쿠키와 장애물은 전체가 화면 밖으로 나간 뒤 정리합니다. 부딪힌 장애물도 화면에 남습니다.

일시 정지 중에는 시간과 이동 발판·미셸 공이 모두 멈춥니다. 캐릭터 표시 높이는 86px입니다.

## 스트릭

피해 없이 쿠키를 모으면 캐릭터 뒤의 달리기 효과가 단계별로 발전합니다. 일반 쿠키와 고양이 쿠키 모두 한 개로 세며, 쿠키를 놓치거나 잠시 못 먹어도 유지됩니다. 실제 피해·낙하 시 초기화되며, 일시 정지 중에는 잔상도 멈춥니다. 다시 시작하면 0개부터 시작합니다.

| 무피해 수집 | 효과 | 고양이 | 쿠키 점수 배율 |
| --- | --- | --- | --- |
| 30개 | 하늘색 빛 잔상 | 1마리 | ×1.5 |
| 120개 | 보라·분홍 잔상과 별빛 | 2마리 | ×2 |
| 300개 | 여섯 색 무지개 꼬리 | 3마리 | ×2.5 |
| 700개 | 더 긴 무지개와 오로라 입자 | 4마리 | ×3 |

하단 진행 바 옆에 현재 단계·스트릭 수·점수 배율이 표시됩니다. 고양이는 유키나가 지나간 경로를 따라 달리고 점프하며 장애물과 충돌하거나 쿠키를 대신 먹지 않습니다. 단계에 도달한 쿠키부터 새 배율이 적용되어 최고 단계에서 일반 쿠키는 30점, 고양이 쿠키는 90점입니다. 피해 시 고양이는 사라지고 배율은 ×1로 돌아갑니다. 점수가 빨리 쌓여 기존 점수 기반 가속 상한에도 더 일찍 도달할 수 있습니다.

## 쿠키 상자

고정 장애물은 초콜릿칩 쿠키 그림과 분홍 리본이 있는 포장 상자입니다. 높은 상자는 48×48px, 낮고 긴 상자는 94×30px이며 기존 충돌 크기와 배치를 유지합니다.

## 미셸 공

미셸의 분홍색 귀·별 모양 눈·크림색 주둥이를 48×48 도트 공으로 그렸습니다. 기존 구르는 장애물의 빈도·속도·충돌 크기를 유지하며, 한 번 만든 그림을 회전시켜 도트 사이에 틈이 생기지 않게 했습니다. 그림은 Canvas 코드로 그리며 외부 이미지를 요청하지 않습니다.

참고: [미셸 공식 소개](https://bang-dream-gbp-en.bushiroad.com/character/hello-happy-world/okusawa-misaki/).

## 파일과 수정

- `docs/index.html`: 화면 및 기본 조작 표시
- `docs/style.css`: 화면 스타일과 모바일 배치
- `docs/bandori-scenery.js`: 미셸 공·쿠키 상자·동행 고양이 도트 렌더링
- `docs/game.js`: 이단점프·입력·속도·코스 연결·충돌·점수·오디오
- `docs/runner-physics.js`: 굴러오는 장애물의 이동·회전·낙하·화면 밖 물체 정리
- `docs/course-patterns.js`: 연속 맵 생성·틈과 착지 폭·동작 조합 중복 방지
- `docs/assets/yukina-sprite.js`: 대기·공중 동작 시트
- `docs/assets/yukina-run.js`: 8프레임 달리기 시트
- `docs/sprite-renderer.js`: 시작 시 한 번 적용하는 배경 마스크
- `.github/workflows/pages.yml`: 검사 후 GitHub Pages 배포

코스 길이는 `DURATION`, 속도는 `targetSpeed()`, 점프는 `jump()`, 굴러오는 장비는 `updateRollingObstacle()`에서 조정합니다. PNG 원본을 수정하면 `node tools/embed-sprite.mjs`로 시트 데이터를 갱신하세요.

## 확인한 내용

서로 다른 맵 5개를 입력만 사용하는 시뮬레이션으로 각각 10분 완주했습니다. 피해나 재시작 없이 모든 동작 종류를 통과했고, 이단점프와 굴러오는 장비 회피, 연속 계단 착지가 실제로 사용됐습니다. 동일한 시드 5개에서 구르는 장비 회피 횟수는 이전 평균 22.8회에서 105.4회로 늘었습니다. 자동 입력의 완주 검증이며 체감 난이도 평가는 포함하지 않습니다.

480·760·1,040px/s에서 긴 틈 27개를 비교했습니다. 최대한 늦게 한 번 뛰어서는 닿지 않고, 정점 부근에서 두 번째 점프를 하면 착지했습니다. 세 속도에서 구르는 장비의 회전·낙하·점프 회피·미회피 충돌을 확인했습니다. 9개의 계단 코스에서 세 발판을 차례로 밟고 정상에 착지하는 것도 확인했습니다.

3,454개 발판과 696가지 동작 조합의 경계 조건, 반대 방향으로 움직이는 발판의 착지, 장비 간격을 검사했습니다. 두 번 입력·길게 누르기·키 반복·세 번째 점프 차단·착지 초기화·입력 버퍼·동시 입력·일시 정지·포커스·화면 밖 정리도 회귀 검사했습니다. 브라우저별 실기기 테스트와 GitHub 원격 배포는 수행하지 않았습니다.

## 크레딧

캐릭터와 세계관은 [BanG Dream! / Roselia](https://bang-dream.com/artist/roselia/)에 기반합니다. 참고한 캐릭터 페이지: [공식 유키나 소개](https://bang-dream.com/artist/roselia/minato-yukina/), [애니메이션 캐릭터 소개](https://anime.bang-dream.com/3rd/character/roselia/). 대사·쿠키 수집 사건은 창작 설정입니다. 유키나 도트는 내장 이미지 생성 도구로 제작하고 게임 프레임으로 적용했습니다. 대기·공중 동작 시트의 체크무늬와 달리기 시트의 녹색 배경은 sprite-renderer.js가 시작 시 한 번 처리합니다. 배경은 Canvas로 그립니다. 공식 작품 및 고군분투와 제휴하지 않은 팬 프로젝트입니다.

## 개발 확인

설치 없이 Node.js로 확인합니다.

```sh
node tests/game.test.cjs
node tests/input.test.cjs
node tests/streak.test.cjs
node tests/double.test.cjs
node tests/rolling-stairs.test.cjs
node tests/course.test.cjs
node tests/platforms.test.cjs
node tests/visibility.test.cjs
node tests/texture.test.cjs
node tests/run-texture.test.cjs
```

생성 도구: 내장 image_gen. 최종 캐릭터 생성 프롬프트는 `source-art/generation-prompt.txt`에 보관했습니다.

달리기 원본은 `source-art/yukina-run.png`, 생성 프롬프트는 `source-art/run-generation-prompt.txt`에 보관했습니다. 두 원본을 수정한 뒤 `node tools/embed-sprite.mjs`를 실행하면 게임용 데이터가 함께 갱신됩니다.
